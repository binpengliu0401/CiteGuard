# Architecture Decision Records

Use this directory for decisions that affect more than one module, are difficult to reverse, or need an enduring explanation beyond a module change-history row.

Do not create an ADR for ordinary implementation details.

## File format

```markdown
# ADR-NNN: Decision title

## Status

Proposed / Accepted / Superseded

## Context

What problem or constraint requires a decision.

## Decision

The selected approach and its boundary.

## Consequences

Benefits, costs and follow-up obligations.

## Alternatives considered

Only alternatives that were seriously evaluated.
```

## Current decisions

No separate ADR is required yet. Current accepted decisions are small enough to remain in the owning module documents.
